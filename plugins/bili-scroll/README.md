# bili-scroll 2.0 ｜ 刷B站 · 深度复刻版

> 每天替你刷一轮 B 站：**通读原文字幕深度排雷**、三档位精选、**默认私信投递（不打扰别人）**、支持**私信双向看片聊天**、**视频卡片墙**与**自动收藏**。
>
> 深度复刻自 [c1overzz/dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll) 2.0.1 核心理念与架构，为 **pi-web-ui** 智能体界面打造原生高性能体验。

---

## 🌟 2.0 核心演进与亮点

1. **从“替你说话”变成“只跟你说”**：
   - **私信投递成为默认 (dmMode: only)**：跑完把结果精简成纯人话发到你的 B站 私信，**公开评论区一条都不发**，不打扰别人。
   - **私信双向 (Bidirectional DM)**：你在 B站 私信里给它发消息或分享视频，它会自动读取原文字幕后回复你。只回主人本人，陌生人一律不回；纯代码轮询，平时零 token 开销。
   - **昵称自动查 UID**：只需在设置里填你的 B站 昵称，插件会自动通过搜索接口解析数字 UID 并缓存，无需手动翻找。
2. **「它刷过的视频」卡片墙**：
   - 封面走宿主代理，防盗链且保护你的 IP 不泄露给第三方图床；
   - 标题、UP主、时长、三档位标签（`值得看` / `可以看` / `不值当`）与为什么值得看；
   - 支持多维筛选（挑中 / 跳过 / 已投递评论）与翻页；
   - 自动为挑中的每条视频拆分沉淀一份单条独立笔记（`reports/<BV>-<日期>.md`），方便个人知识库或 Obsidian 归档。
3. **自动收藏到目标收藏夹**：
   - 宿主直接集成收藏夹操作 API，可在偏好设置中下拉选择你的 B 站收藏夹；
   - 巡检结束后自动将今日挑中的干货视频加入目标收藏夹，无需任何手动操作。
4. **实时动作视窗 (Live Action Terminal)**：
   - 拒绝黑盒运行：搜视频、拉字幕、排雷分析、写日报、发私信，全流程步骤实时透明推送到终端窗口。
5. **四页签精细化控制台**：
   - **日常 (Daily)**：峰谷巡检配额、实时状态、快捷操作、视频卡片墙与日报展开。
   - **偏好 (Taste)**：人设提示词（可一键从当前工作区导入 `AGENTS.md`）、关注关键词、排除词、收藏夹绑定、日报精细度（完整 / 薄版 / 不写）。
   - **互动 (Social)**：投递方式（只私信 / 评论+私信 / 只发评论）、私信 UID 与昵称、私信双向开关、评论与楼中楼回复安全闸。
   - **高级 (Advanced)**：扫码登录与凭证管理、Python 主依赖与本地 Whisper 转写依赖安装、真机连通性测试（测一下）、复制诊断信息、环境自检、评论复核。

## 🛠️ 注册的 AI 工具列表 (Agent Tools)

| 工具名称            | 描述             | 核心用途                                                    |
| :------------------ | :--------------- | :---------------------------------------------------------- |
| `bili_whoami`       | 检查登录状态     | 验证凭证有效性、当前用户昵称、UID 与状态                    |
| `bili_login_start`  | 扫码出码         | 生成 B 站 App 扫码登录的二维码 URL 与 Session Key           |
| `bili_login_poll`   | 轮询扫码结果     | 轮询扫码状态并在成功时自动保存凭据到 `bili_credential.json` |
| `bili_search`       | 检索视频         | 支持关键词、排序依据（综合/播放/最新/弹幕）与分页           |
| `bili_video_info`   | 视频详情         | 获取播放量、点赞、投币、收藏、分 P 列表与简介               |
| `bili_subtitle`     | **原文字幕提取** | 深度提取带时间戳的字幕全文或 AI 智能总结                    |
| `bili_hot_videos`   | 全站热门         | 发现当前全站综合热门推荐流                                  |
| `bili_rank`         | 分区排行榜       | 获取全站或各指定分区的最新排行榜单                          |
| `bili_comments`     | 视频评论         | 提取热门评论与观众高赞讨论                                  |
| `bili_reply`        | 发表评论/回复    | 视频留言互动（受安全闸门严格限制）                          |
| `bili_send_message` | **发送B站私信**  | 直接向指定 UID 发送私信通知（≤500 字符限制）                |
| `bili_status`       | 查看巡检状态     | 今日挑选额度进度、巡检轮次与日报路径                        |
| `bili_duty_run`     | **立刻刷一轮**   | 立即启动全流程巡检与生成今日速报                            |
| `bili_resolve_uid`  | 根据昵称查 UID   | 通过昵称搜索解析数字 UID 并缓存                             |
| `bili_fav_folders`  | 收藏夹列表       | 获取当前登录用户创建的所有视频收藏夹                        |
| `bili_fav_add`      | 添加视频收藏     | 将指定视频快速添加到用户收藏夹                              |

## 📱 首次使用与快速上手

1. 打开 **bili-scroll** 控制台，进入 **高级** 页签，点击 **「📱 扫码登录」**；
2. 手机打开哔哩哔哩 App 扫码确认，勾选长期登录；
3. 进入 **互动** 页签，填入你的 B 站昵称（例如：`张三`），投递方式保持默认的 **只私信 (only)**；
4. 回到 **日常** 页签，点击 **「⚡ 现在跑一轮」**，即可在下方动作视窗中实时看到 AI 通读字幕与挑选结果，随后在你的手机 B 站私信中收到推荐通知！
