# Wallpaper Engine 动态壁纸插件 (v0.3.0)

把本机 **Wallpaper Engine** 的创意工坊壁纸无缝融入到 `pi-web-ui` 的对话界面后方，配合液态毛玻璃磨砂效果、透明度微调、WebGL2 场景渲染、音频频谱联动与自动轮播。

参照 [dsh-wallpaper-engine](https://github.com/elysia395/dsh-wallpaper-engine) 方案，专为 `pi-web-ui` 定制。**不向模型注册额外工具或提示词，不增加任何 Token 开销。**

---

## 核心特性

- 🎮 **全盘 Steam 库深度检索**：自动读取 Windows 注册表与 Steam 配置文件 `libraryfolders.vdf`，自动探测全盘跨分区各库中的 Wallpaper Engine 创意工坊壁纸（AppID `431960`）与默认壁纸。
- 🎬 **全格式壁纸支持**：
  - **Video（视频）**：支持 HTTP 206 Range 分片流式加载，高画质 MP4 / WebM 流畅循环与静音切换。
  - **Scene（场景）**：集成 WebGL2 实时渲染引擎（基于 `webwallgl`），支持 `.pkg` 资源包解析、粒子系统、骨骼动画与着色器动态光影。
  - **Web（网页）**：沙箱 `<iframe>` 隔离挂载，内置 Wallpaper Engine 常用属性与事件垫片注入。
  - **Image（静态图）**：JPG / PNG / WebP 全屏高质量居中自适应渲染。
- 🎵 **音乐频谱响应联动**：内置声学频谱波形模拟与采集器，支持将音频律动实时注入到具备音频反应能力的 Web 与 Scene 场景壁纸中。
- ⭐ **壁纸收藏与自动轮播**：
  - 点击壁纸卡片右下角的 **⭐** 即可快速加入/移除收藏，并支持专属“⭐ 收藏”分类标签；
  - 支持设定 **5分钟 / 15分钟 / 30分钟 / 1小时** 自动定时轮播，也可在抽屉顶部点击 **🎲 切下一张** 立即随机切换。
- 📤 **外观预设导入与导出**：支持一键将当前激活壁纸、毛玻璃模糊度、不透明度与收藏夹配置导出为独立 JSON 快照，或从剪贴板导入分享方案。
- 🧊 **液态毛玻璃效果（Liquid Glass）**：通过 CSS 变量动态驱动界面各层磨砂质感，支持模糊半径（0-32px）与界面底色不透明度（40%-100%）实时无缝调节。
- 🕹️ **交互与穿透模式**：支持开启“允许交互”模式，让鼠标可以穿透聊天对话区与背景中的 Web / Scene 动态壁纸产生实时交互。
- ⚡ **智能能耗管理**：
  - 可设定 **30 FPS / 60 FPS / 无限制** 帧率上限，兼顾流畅与显卡省电。
  - 页面切入后台隐藏时，自动挂起视频播放与 WebGL 渲染循环，绝不抢占编程与模型生成算力。
- 🪟 **沉浸式壁纸抽屉**：顶栏一键展开抽屉面板，支持按标题/标签实时搜索、多维度分类筛选（全部/收藏/视频/场景/网页/静态图）、网格多页翻页浏览（大幅降低海量壁纸 DOM 与图片并发负载）、封面原始纵横比 1:1 保真渲染（不压缩裁剪画面，搭配毛玻璃氛围底光）与即时切换。

## 支持的壁纸类型对照

| 类型                    | 说明                         | 支持情况    | 渲染机制                                   |
| ----------------------- | ---------------------------- | ----------- | ------------------------------------------ |
| **Video（视频）**       | MP4 / WebM / M4V             | ✅ 完全支持 | 原生 `<video>` 硬件加速，HTTP 206 流式分片 |
| **Scene（场景）**       | 2D/3D 动态场景 (`.pkg`)      | ✅ 完全支持 | `webwallgl` WebGL2 实时渲染，失败平滑降级  |
| **Web（网页）**         | HTML / JS / CSS 网页壁纸     | ✅ 完全支持 | 沙箱隔离 `<iframe>` + WE API 垫片          |
| **Image（静态图片）**   | JPG / PNG / WebP             | ✅ 完全支持 | 全屏自适应渲染与缩略图                     |
| **Application（应用）** | 需启动外部 `.exe` 的程序壁纸 | ❌ 不支持   | 自动过滤，不进入候选列表                   |

## 协议与 API 路由

所有 HTTP 接口挂载于 `/plugins-api/wallpaper-engine/api/*`：

| 路由                        | 方法   | 功能描述                                               |
| --------------------------- | ------ | ------------------------------------------------------ |
| `/api/wallpapers`           | `GET`  | 获取本机已扫描到的所有壁纸列表、当前激活状态与收藏集合 |
| `/api/rescan`               | `GET`  | 清理服务端缓存，重新全量扫描各磁盘驱动器的 Steam 库    |
| `/api/preview?id=:id`       | `GET`  | 读取壁纸缩略图（带 24 小时 HTTP 客户端缓存）           |
| `/api/media?id=:id`         | `GET`  | 读取视频或主文件（支持 HTTP 206 Partial Content 分片） |
| `/api/pkg?id=:id`           | `GET`  | 读取 Scene 场景壁纸二进制 `scene.pkg` 数据包           |
| `/api/project?id=:id`       | `GET`  | 读取壁纸原始 `project.json` 配置清单                   |
| `/api/web?id=:id&file=:rel` | `GET`  | 网页壁纸静态资源安全沙箱服务（严格路径校验防逃逸）     |
| `/api/favorite`             | `POST` | 切换指定壁纸的收藏状态（收藏/取消收藏）                |
| `/api/presets`              | `GET`  | 导出当前壁纸选择与毛玻璃外观配置预设 JSON              |
| `/api/presets`              | `POST` | 导入并应用外部外观配置预设 JSON                        |
| `/api/active`               | `GET`  | 获取当前使用的壁纸、轮播设置及毛玻璃参数               |
| `/api/active`               | `POST` | 保存当前壁纸与参数变更，并向其它已连接标签页广播同步   |

## 使用方法

1. 确保电脑已安装 Steam 并订阅了 Wallpaper Engine 创意工坊壁纸；
2. 启动 `pi-web-ui`，在顶部导航栏右上角点击 **🖼️ 壁纸** 图标；
3. 在展开的抽屉中浏览已识别的壁纸（可通过分类标签切换“全部”、“⭐ 收藏”、“视频”、“场景”、“网页”或“静态图”）；
4. 点击卡片上的 **☆** 将喜欢的壁纸加入收藏，点击卡片主体即可立即应用；
5. 可在抽屉顶部根据个人喜好调节：
   - **模糊度与不透明度**：微调出最舒适的透光磨砂质感；
   - **自动轮播**：选择轮播间隔时间（如每 15 分钟），或点击“切下一张”手动换壁纸；
   - **音乐频谱**：开启后具备音频反应能力的壁纸将跟随声音律动；
   - **允许交互**：开启后鼠标可在对话区空隙与背景交互；
   - **导出/导入预设**：一键保存或分享外观方案；
   - **关闭壁纸**：随时一键还原为原生实色界面。
