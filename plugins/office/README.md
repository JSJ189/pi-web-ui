# Office 预览与编辑插件

基于 Univer 的 Office 画布与结构化 AI 操作。支持 `.xlsx`、`.docx`、`.pptx`、`.csv`、`.tsv`。宏文档及旧二进制格式不接管、不写回，请先使用 Office 或 LibreOffice 转换为受支持格式。

## 使用与保存

在工作区文件树打开文档。运行时首次使用时按需下载，后续复用本地资产。插件不在激活时启动网关；空闲 15 分钟后休眠，有正在执行的操作时不会休眠。

本机与远程页面统一使用无同源权限的沙箱画布，通过 MessageChannel 和已鉴权的插件接口转发文档范围内的 HTTP、XHR 与 WebSocket。浏览器不能直接访问网关；网关限制在当前实例缓存目录，并拒绝浏览器 Origin、Fetch Metadata 和非 loopback Host。画布启动失败时提供结构化只读文本预览，编辑及保存按钮禁用。

首次画布启动会在服务端合并固定运行时资源（约 62 MiB），后续文档复用内存构建缓存。运行时适配针对当前固定版本，不兼容的版本会明确失败。部署时需安装插件 package.json 声明的 `esbuild`、`ws` 依赖；缺依赖时给出安装提示，不在请求中同步阻塞宿主安装。

画布修改后点击保存或按 Ctrl/Cmd+S。状态栏显示保存中、成功或错误。运行时没有可靠的修改事件协议，因此插件不宣称能够精确显示“有未保存修改”，关闭前请主动保存。重新加载会丢弃当前画布状态并从磁盘读取，界面会先确认。

保存绑定首次导入时的磁盘版本。原文件被其他程序修改或替换后返回冲突，不覆盖外部修改；可以另存为一个不存在的同扩展名文件，或重新加载。另存为不切换当前文档路径。写入使用同目录排他临时文件、fsync 和原子提交，保留已有文件的权限；新文件禁止覆盖。现有文件的版本校验属于乐观并发控制，无法对其他进程提供文件系统级比较并交换保证。

格式导入导出受 Univer 能力限制。图表、批注、公式、母版、复杂排版及外部引用的保留情况需用实际文档验证，不承诺与 Microsoft Office 完全一致或无损往返。重要文件建议先另存为。

## 资源与生命周期

- 每个插件实例使用独立临时缓存，文档标识取完整路径 SHA-256。
- 同一文档的服务端读、编辑、保存操作串行执行；画布内部协作仍由 Univer 网关管理。
- 文件和导出上限 64 MiB，每次表格读取最多 10,000 个单元格，Worker 输出上限约 1 MB。
- 同时最多保留 32 份文档，达到上限明确报错，不自动驱逐可能尚未保存的文档。停用插件释放缓存；重新加载文档保留原有文档槽位。
- 下载校验固定 SHA-256；取消与插件停用传播至网关请求和 Worker。运行时通过宿主资产流水线安装。
- 画布会话使用独立随机令牌，最多 16 份，闲置 10 分钟失效；每会话最多 8 个 WebSocket、32 个并发请求，单次上传 6 MiB、响应 16 MiB；每会话累计上传 32 MiB、请求正文和 Socket 发送累计 64 MiB，队列与等待时间有上限。
- iframe 保持 `allow-scripts allow-downloads`，不授予同源权限；CSP 禁止直接网络连接。浏览器内缓存仅保留在内存，持久保存通过宿主执行。
- `PI_WEB_OFFICE_IDLE_TIMEOUT_MS` 调整休眠时间，最小 60 秒。

## 开发验证

```sh
npx vitest run tests/unit/office-*.test.ts
node tests/office-canvas-test.mjs
```

覆盖工作区与符号链接边界、缓存隔离、并发启动、重复保存、外部修改冲突、排他另存为、前端销毁取消、轮询边界、消息桥、文档传输范围和网关浏览器请求拦截。

真实 Chrome 已验证无同源权限的沙箱画布、键盘修改、协作提交、另存为 XLSX 后新文档转换重读、零外部请求及完整清理；截图和报告默认输出到 `.tmp-verify-data/`。浏览器测试缺 Chrome 或运行时资产时跳过，不消耗模型 token。

真实运行时已验证 XLSX 编辑保存及重启重读、DOCX/PPTX 文本导入导出保留、CSV/TSV 编辑导出和分隔符转义。最小样本文档通过不代表复杂格式视觉保真，图表、批注、公式、母版及复杂排版仍需实际样本验证。
