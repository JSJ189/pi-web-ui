# Live2D 看板娘 (Live2D Companion) 插件

基于 **Live2D Cubism 2 / 3 / 4** 与 **PixiJS** 的页面级智能体桌面陪伴看板娘，为 `pi-web-ui` 注入生动的交互生命力。

---

## 🌟 核心特性

- **多代 Live2D 模型全支持**：同时支持 Cubism 2（`.model.json`）与 Cubism 3/4（`.model3.json`），内置 4 套官方离线开源模型（🌸 雫 / 🌿 春 / ☀️ 日和 / 🐶 萌柴），零外网即可秒开！
- **自然视线与头部跟踪**：
  - **👀 鼠标视线跟随（Mouse Tracking）**：眼珠与头部随光标在屏幕上的移动自然偏转；
  - **💤 自然呼吸待机（Natural Idle）**：轻柔呼吸起伏与随机眨眼；
- **丰富的触摸与动作反馈**：
  - 单击头部：触发摸头动作，展露开心笑容与亲切气泡台词；
  - 单击身体：害羞/惊讶微动反应；
  - 双击角色：触发晃动并随机送出温馨问候与灵感提醒；
- **AI 对话情绪深度联动**：
  - 智能体思考 / 工具调用中：看板娘展露专注思考表情并冒出思考气泡；
  - 智能体完成回答：看板娘开心点头与打招呼；
  - 智能体遇到报错：看板娘展露关切与吃惊表情；
- **完全自由的页面悬浮控件**：
  - **自由拖拽**：鼠标左键按住即可拖动到屏幕任意位置，自动记忆坐标；
  - **滚轮缩放**：在挂件上滚动鼠标滚轮即可随心调整大小比例（0.4x ~ 2.0x）；
  - **快捷悬浮操作条**：鼠标悬停在挂件侧边，平滑滑出表情切换、换装、模式切换、设置与收起按钮；
  - **右键上下文菜单**：右键点击弹出完整控制菜单；
  - **极简挂起胶囊**：点击收起后在屏幕右下角留存可爱小猫爪（🐾），点击随时唤回；
  - **全局快捷键**：按下 `Alt+L` 或点击顶栏按钮随时切换显隐。
- **点击穿透与透明放行**：
  - **✨ 智能透明像素穿透**：默认开启！光标在人物周围透明区域时，所有鼠标点击、文字选中、滚轮滚动 100% 自然穿透到底层网页，绝不阻挡操作；光标移至角色实体时自动激活摸头拖拽；
  - **👻 完全点击穿透模式 (Ghost 幽灵模式)**：在右键菜单、悬浮快捷栏（👻）或设置面板中一键开启，看板娘进入纯观赏模式，完全不拦截任何鼠标交互，丝毫不阻碍打字与看文档；
- **本地模型一键上传与管理**：
  - **📦 支持 ZIP 压缩包上传**：支持将下载好的 Live2D 模型 `.zip` 压缩包一键拖入或选择上传，服务端自动解压、智能嗅探 `.model3.json` / `.model.json` 并即刻换装；
  - **📂 支持本地模型文件夹上传**：直接从电脑中选择已解压的模型目录批量上传；
  - **🗑️ 模型管理与清理**：在设置面板中可一键删除已上传的自定义模型，释放磁盘空间。

## 🤖 AI 智能体专属操控工具

插件向 pi 编码智能体注册了统一操控工具 `live2d`，智能体可在回复用户时主动与看板娘产生互动：

| 工具名称 | 功能描述                                                       | 核心操作 (action)                                                                                                                                                    |
| :------- | :------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `live2d` | 统一看板娘操控工具：模型切换、表情、气泡、音乐口型对齐、眨眼等 | `list_models`, `get_current_model`, `list_expressions`, `play_expression`, `show_bubble`, `switch_mode`, `switch_model`, `play_audio`, `stop_audio`, `trigger_blink` |

---

## 📡 HTTP API 接口

插件通过 `/plugins-api/live2d/*` 暴露 HTTP 路由：

- `GET /models`：获取全部已配置模型列表与当前状态；
- `GET /current-model`：获取当前展示的模型；
- `GET /expressions`：获取模型表情列表；
- `POST /action`：触发看板娘动作（兼容 `live2d_pet` 协议）：
  - 播放表情：`{"action": "expression", "name": "happy"}`
  - 显示气泡：`{"action": "message", "text": "你好！", "duration": 4000}`
  - 切换模式：`{"action": "mode", "mode": "mouse"}`
  - 切换模型：`{"action": "model_switch", "model": "shizuku"}`
