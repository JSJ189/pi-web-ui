# live-preview（实时预览）

Live Server 式预览插件，无独立视图 tab——在右栏文件树上点右键用：

- 🌐 **Live Server 打开**：右键文件夹 → 打开该目录；右键文件 / 列表空白处 → 打开当前目录；点击直接新标签打开 `/liveserver/...`（相对路径的 css/js/图片可用，改文件自动刷新）。
- 📝 **预览 Markdown**（仅文件行显示）：`.md` 文件走 `/md/...` 渲染，其它文件回落到 Live Server；点击直接新标签打开。
- 🧭 **标题导航**（`/md` 页）：左侧一列目录，滚动高亮、点击跳转、拖动改宽、`Ctrl/Cmd+\` 折叠；开关与宽度记在浏览器本地。标题不足 2 个、或正文自带标题 id 时不注入。

真服务只绑 `127.0.0.1:随机口`（外部直连不可达也无妨），经宿主**通用代理**
（`host.registerProxy`）对外只露 `/liveserver` 与 `/md` 两个同源前缀。

AI 可用 `live_preview` 工具（参数 `path` 可给文件或目录，缺省根目录）拿预览地址；
默认浏览器自动新标签打开（工具参数 `open:false` 或本页设置关闭可停；浏览器拦截弹窗时点结果里的链接）。

## 说明

- 根目录 = 当前工作区（`set_cwd` 切项目后刷新即看新项目），越界路径一律拒绝；
- 文本走宿主解码（UTF-8 失败回落 GBK），老中文页面不乱码；
- 预览文件上限 10MB；单段 `Range` 已实现（mp4 拖进度条可用）；
- 需要能力 `http`（注册代理）+ `fs`（读工作区）+ `tools`（`live_preview` 工具）+ `ui`（右键菜单）；
- 设置里可关自动刷新；顶栏后台任务面板可停掉内建服务（重载插件恢复）。
