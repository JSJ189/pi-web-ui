# AI 响应速度监控插件 (Response Speed)

实时监控并在底部状态栏展示 AI 的最新响应速度与平均响应速度，支持 AI 自循环的每一次循环独立测速。

## 什么是响应速度？

**响应速度**（首字响应时间 / Time to First Token，简称 **TTFT**）：
指的是**把消息请求发给 AI，到收到 AI 返回的首个回复响应数据包的时间**。

它反映了模型网络延迟、推理冷启动排队、服务端处理与首 Token 生成的综合时延。

## 主要特性

- 📊 **底部状态栏双指标展示（最新 / 平均）**：
  - 在底栏（`bottombar`）以现代化极简徽章直观呈现当前对话最新一次请求与历史平均响应速度（精简纯数值如 `12.7/14.3`，鼠标悬浮展示详细说明与毫秒耗时）；
  - 纯净稳定：不显示“响应中…”，始终直接显示该对话上一次的耗时，不破坏阅读沉浸感；
  - 纯净设计：不注入右上角悬浮窗，不 hack 底层 WebSocket，完全由服务端权威运行轨迹驱动。
- 💬 **每个对话独立记录与隔离**：
  - 各会话独立记录与统计 TTFT 响应数据，互不干扰；
  - 切换对话时底栏即时无缝联动更新为对应对话的最新与均速，新建对话即从空态开始独立测速。
- 🔄 **支持 AI 自循环每次独立测速**：
  - 当 AI 调用工具并在工具执行完后进入自循环（多回合 turn）时，每一轮向大模型发起的新请求都会**独立计算耗时**；
  - 准确捕捉每一个回合的首包响应时延。
- 📈 **多维统计与看板**：
  - 点击底栏徽标，弹出当前对话的响应速度统计看板（Dashboard）；
  - 查看平均响应速度 (Average Latency)
  - 查看当前/最新回答速度 (Latest Latency)
  - 查看最快与最慢响应时间 (Min / Max Latency)
  - 历史测速样本明细表格与一键清空当前对话记录。

## 安装与配置

插件位于官方插件体系 `plugins/response-speed`，开箱即用。
在设置 -> 界面插件 中启用即可生效。
