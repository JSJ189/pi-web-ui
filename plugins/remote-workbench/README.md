# 🖥️ remote-workbench — 远程工作台插件

在 pi-web-ui 界面中提供一个统一的远程主机资产管理平台、画布/分屏终端矩阵、轻量 SFTP 树浏览、端口转发与 AI 远程批处理执行环境（深度对标 Termcp 设计理念）：

- **唯一全局主机事实源（`<dataDir>/global-hosts.json`）**：
  - 与顶栏/右下角切换目录中的「远程工作区 (SSH)」及「SFTP 插件」完全共享配置与 AES-256 加密凭据。
  - 在任意一处添加的主机（如 `ubuntu@82.156.246.55`），在远程工作台、SFTP 面板和远程工作区中秒级可见，**一次配置，处处可用**。
  - 自动无损继承并迁移旧版本的 `ssh-profiles.json`。
- **类似画布的多终端矩阵查看模式（Canvas Dashboard）**：
  - **彻底告别只能单看一个 Tab 的局限**：支持在终端顶部工具栏一键切换布局：
    - **📑 单标签模式**：传统单标签页视图，专注于单台机器；
    - **◫ 左右双列平铺**：两台服务器左右对齐，方便一边 tail 日志一边编译执行；
    - **⊞ 四宫格矩阵**：同屏查看 4 台核心节点（如 Web、DB、Redis、Worker）；
    - **🎨 自适应画布卡片平铺**：类似白板/画布，所有连接的主机像便签卡片一样响应式平铺在视口中，每张卡片都有独立的 xterm 实例，全屏状态一目了然！
  - **独立最大化/聚焦**：点击任意终端卡片右上角的 **「⛶」**，可一键将其放大至视口全屏，再次点击恢复多屏平铺。
  - **一键平铺全部主机**：在主机看板点击 **「🎨 画布平铺全部主机」**，自动为所有机器并发建立终端并矩阵平铺。
- **多机广播同步输入（Cluster Broadcast / Sync Input）**：
  - 点击工具栏 **「⚡ 广播输入」** 切换开关（开启 / 关闭）；
  - 开启后，你在任意一个终端敲击的按键（如 `uptime\r`、`docker ps\r`、快捷指令条按钮等），将**毫秒级并发广播发送给所有已连接终端**（类似 ClusterSSH / tmux sync-panes），集群批量巡检与命令下发提效数倍！
- **~/.ssh/config 本机资产自动发现与批量导入**：
  - 工具栏提供**【⚙ 导入 ~/.ssh/config】**，自动扫描并解析 OpenSSH 配置文件（对齐 `ssh_config(5)` 规范）；
  - 智能识别主机别名（Host）、IP 地址（HostName）、端口（Port）、用户名（User）与私钥文件（IdentityFile）；
  - 标记已在全局库的主机与新发现的主机，支持勾选后一键导入到 `global-hosts.json`。
- **内置轻量 SFTP 远程文件树浏览抽屉**：
  - 主机卡片提供**【📂 文件】**按钮，在面板内直接滑出轻量文件树抽屉；
  - 快速进入远程目录、查看目录结构、文件大小与修改时间；
  - **双击文件快速文本预览**（只读探测 + 语法高亮查看，不占用编辑器标签）；
  - 支持直接从本机选择文件上传至当前所在远程目录。
- **凭据外带直通（Out-of-band Credential Prompt）**：
  - 对标 Termcp 的安全输入机制：实时嗅探终端输出流中的 `[sudo] password for` / `Password:` / `Enter passphrase` 等提权提示。
  - 触发后在视口中央自动滑出独立的安全密码输入框，敲击回车直接将密码注入底层 PTY `stdin` 并立刻销毁输入框。
  - **密码绝不进入大模型上下文，不进本地日志文件**，彻底避免交互死锁与凭据泄露。
- **终端输出清洗与 Token 瘦身导出（Termcp `ansi.Compact` 移植）**：
  - 完整移植 Termcp 的两级压缩算法：自动剥离 ANSI 控制序列，并将 `git clone` / `npm install` 等工具产生的上万次 `\r` 覆盖进度条**折叠为最终一行**。
  - 工具栏提供**【📄 导出日志】**：一键将数千行终端输出清洗为纯净文本并复制/下载，可节省高达 90%~98% 的无意义 Token，极度适合发给 AI 排查问题。
- **高危命令安全审阅保护（Approval Gate）**：
  - 主机支持勾选**「🛡️ 开启高危指令审阅保护」**（标记敏感/生产机器）；
  - 开启后，AI 智能体通过 `remote_term` 工具发起的带有风险或破坏性的命令（如 `rm -rf /`、`mkfs`、`DROP DATABASE`、`shutdown` 等）会被自动阻断拒绝，必须人工接管或在安全终端中执行。
- **AI 批处理执行工具（`remote_term`）**：
  - 遵循 Termcp “Turns 是最昂贵资源，1 个 Command = 1 个 Batch” 的调用哲学，向智能体注册 `remote_term` 工具。
  - 动作包含 `run`（执行命令并自动经 Compact 清洗）、`list`（列出全局可用主机）、`probe`（探测远端机器系统与包管理器）。
- **SSH 端口转发隧道管理（-L Tunnels）**：
  - 独立「端口转发」标签页，通过已建立的 SSH 链接进行本地端口映射（如将本机的 `127.0.0.1:8080` 转发到远程内网的 `localhost:3000` / `6379`）。
  - 支持查看运行中隧道、连接状态与一键启停。
- **常用运维指令快捷条（Snippet Bar）**：
  - 终端上方提供快捷按键与高频排查指令条（`Ctrl+C`、`Ctrl+D`、`Esc`、`Tab`、`clear`、`top`、`htop`、`df -h`、`free -m`、`docker ps`、`tail syslog`），支持一键点击注入执行。

## 快速上手

1. **多终端画布分屏与矩阵查看**：
   - 打开顶部导航栏 **「🖥️ 远程工作台」**；
   - 点击右上角 **「🎨 画布平铺全部主机」**，或在终端选项卡通过右侧切换器选择 **「◫ 双列」**、**「⊞ 四格」** 或 **「🎨 画布」**；
   - 所有打开的会话如画板卡片般同屏并排展示，每台机器都可以独立滚动与键入；
   - 点击单个终端卡片右上角 **「⛶」** 即可单窗口独占放大，再次点击恢复平铺。
2. **多机广播输入（Cluster Broadcast）**：
   - 点击工具栏 **「⚡ 广播输入」** 切换为开；
   - 在任意终端输入命令（如 `cat /etc/os-release`），所有打开的主机同时执行并输出结果。
3. **一键导入本机 SSH 配置**：
   - 点击搜索框旁的 **「⚙ 导入 ~/.ssh/config」**，勾选系统已有的主机，点击 **「一键导入已选主机」** 即刻生成全局资产卡片。
4. **轻量浏览远程文件与日志**：
   - 在主机卡片上点击 **「📂 文件」**，弹出文件浏览抽屉；
   - 双击文件夹即可进入目录，双击文本/配置文件直接打开弹窗预览内容，亦可直接点击 **「⬆ 上传」** 传输文件。
5. **安全处理 Sudo 提权**：
   - 执行 `sudo` 时，视口中央自动滑出凭据直通弹条，回车后密码直通 PTY，不留日志痕迹。
