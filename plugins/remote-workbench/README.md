# 远程工作台

远程工作台复用宿主 `remoteSsh` 服务和 `<dataDir>/global-hosts.json`，与远程工作区、SFTP 插件共享 SSH 主机和加密凭据。插件自己的分组、任务、命令片段和隧道配置独立保存，不复制 SSH 密码。

## 主机与配置导入

主机看板支持搜索、分组及环境标记；环境和分组是工作台元数据，不改变宿主 SSH 凭据。健康检查按需发起，返回负载、内存和磁盘指标；无法采集的指标不会伪造为正常值。

导入 `~/.ssh/config` 时支持关键字大小写、带引号的路径、多个主机别名、通配继承、排除规则、首次赋值优先和 Include 文件展开。Include 限制为 8 层、64 文件、合计 1 MiB，防止循环和无界扫描。

`ProxyJump`、`ProxyCommand`、`Match` 等宿主无法完整表达的连接语义会明确显示警告并阻止导入。Include 失败也会阻止不完整配置导入。导入时服务端重新扫描，不能靠修改浏览器提交参数绕过检查。

## 终端与会话恢复

支持标签、双列、四格、自适应平铺及独立终端最大化。终端以字节流写入 xterm，保留 UTF-8 跨包字符；输出有界排队，并通过消费确认控制 SSH 输出速度。

关闭工作台面板与关闭终端是不同操作：面板卸载会脱离终端，显式关闭终端会关闭 SSH 通道。同一浏览器标签页保存不可猜测的恢复凭据，可在重新挂载时恢复；凭据不写入共享主机配置。脱离会话有过期时间，插件重载或服务重启会清理内存中的 SSH 通道。

需要跨服务重启保留远端任务时，可选择 tmux 模式，前提是目标机器已安装 tmux。关闭 SSH 通道并不等于终止 tmux 内的进程。

终端提供缓冲区搜索、参数化命令片段、多行粘贴预览和日志导出。广播开启时显示实际目标清单；凭据输入只发送给对应终端，不进入广播或模型上下文。终端输出本身仍可能包含远端程序回显，不能替代远端程序的保密设置。

## 多机任务与 AI 命令

任务中心支持选择主机、设置并发、查看逐机状态、取消任务和重试失败主机。重试只执行选中的失败项，不重复执行成功主机。运行态和配置写入失败会反馈给用户，服务重启后未完成任务标记为中断，不自动重复执行命令。

`remote_term` 支持列出主机、探测、执行命令和按日志 ID 分页读取输出。命令执行使用有界输出摘要，并将完整输出保存在有总量限制的本地日志中；达到限制时会说明截断情况。日志可能包含命令及其输出中的敏感信息，不应将密码直接放在命令行。

超时、用户取消及插件卸载会关闭执行通道并回收监听。SSH 协议不能保证远端进程及其所有子进程已经停止，结果会明确说明这一限制；有副作用的任务应在重试前核对远端状态。工作目录使用 shell 参数引用，路径中的空格和特殊字符不会改变命令结构。

主机的高危指令保护只用于拦截已知危险模式，不能完整理解任意 Shell、脚本或 SQL；生产环境仍应使用最小权限账户。

## 隧道与文件

端口转发监听运行 pi-web-ui 服务的机器上的 `127.0.0.1`，并非访问页面的浏览器所在机器。支持保存配置、启动、停止、删除、查看状态与错误、按配置重连。停止隧道会同时关闭监听及已建立连接。

轻量文件面板提供目录浏览、有限大小的文本预览和文件上传。上传限制文件名与大小，使用排他创建，避免无意覆盖已有远端文件。复杂传输继续使用共享主机配置的 SFTP 插件。

## 验证与开发

- `npx vitest run tests/unit/remote-workbench-*.test.ts`：配置解析、执行取消与预算、终端归属及恢复、任务与隧道生命周期。
- `node tests/remote-workbench-ui-test.mjs`：独立 Mock 后端的浏览器交互回归，不访问真实 SSH 主机；Chrome 探测使用 `tests/lib/chrome.mjs`。
- 修改插件代码时递增 `manifest.json` 版本，并同步本地数据目录中的插件。若安装目录是指向本仓库的目录联接，源码已同步，但服务端仍需重载插件后才会使用新模块。
