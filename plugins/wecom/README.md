# 企业微信工作台与机器人 (WeCom Plugin)

> 企业微信群机器人与自建应用插件，支持双向会话对话、结构感知 Markdown 智能分块、白名单安全准入与群机器人 Webhook 卡片推送。零外部依赖（Node 内建 fetch + node:crypto）。

## 功能特性

- 🤖 **企微机器人双工对话**：支持在企业微信中与 AI 助手对话，自动维护独立用户会话隔离与多轮上下文。
- 📦 **结构感知 Markdown 分块**：针对企业微信消息长度限制，采用类似 `dsh-im` 的智能分块算法，保证代码块（\`\`\`）闭合与语法高亮不破损。
- ⚡ **斜杠快捷指令**：支持 `/help`、`/clear` 或 `/new`（清空上下文开启全新对话）、`/status`（查看机器人在线指标）。
- 🛡️ **安全白名单控制**：支持设置允许对话的成员 UserId 白名单，未授权人员友好拦截，防止误触。
- 📣 **群机器人 Webhook 推送**：支持群机器人 Webhook，一键推送 Markdown 告警、发布通报与状态卡片。
- 🛠️ **AI 企微工具**：向 AI 助手注册 `wecom` 工具，AI 可自主向企业微信群推送通知和状态报告。

## 配置指南

### 1. 群机器人 Webhook (快速接入群消息推送)

1. 在企业微信电脑端打开目标内部群；
2. 点击右上角「...」→「添加群机器人」→「新创一个机器人」；
3. 复制生成的 Webhook 地址中的 `key` 参数（例如 `693a91f6-7xxx-4xxx-xxxx-xxxxxxxxxxxx`）；
4. 在 pi-web-ui 企业微信面板填入 Webhook Key 即可使用推送和双工回复能力。

### 2. 企业自建应用 API (发送单聊/应用消息)

1. 登录 [企业微信管理后台](https://work.weixin.qq.com/)；
2. 进入「应用管理」→「自建」→「创建应用」；
3. 获取应用的 `AgentId` 与 `Secret`；
4. 在「我的企业」页面底部获取 `CorpID`；
5. 在 pi-web-ui 填入 `CorpID`、`CorpSecret` 与 `AgentId`。
