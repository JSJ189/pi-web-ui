# 钉钉机器人与工作台 (DingTalk Plugin)

> 钉钉企业自建机器人与自定义群机器人插件，支持双向会话对话（Stream / 回调）、结构感知 Markdown 智能分块、白名单安全准入与自定义 Webhook 卡片推送。零外部依赖（Node 内建 fetch + node:crypto）。

## 功能特性

- 🤖 **钉钉机器人双工对话**：支持在单聊或群聊中与 AI 助手对话，支持独立用户会话隔离与多轮对话。
- 📦 **结构感知 Markdown 分块**：针对钉钉消息长度限制，采用类似 `dsh-im` 的智能分块算法，保证代码块（\`\`\`）闭合与语法高亮不被截断。
- ⚡ **斜杠快捷指令**：支持 `/help`、`/clear`、`/new`（开启新会话）、`/status`（查看机器人运行健康状态）。
- 🛡️ **安全白名单控制**：支持指定允许对话的 Staff ID 列表，未授权人员友好提示，防止群内误触或 token 盗刷。
- 📣 **群自定义 Webhook 推送**：支持群机器人 Webhook 与 HMAC-SHA256 签名加签，可单向推送 Markdown 告警与通知卡片。
- 🛠️ **AI 钉钉工具**：向 AI 助手注册 `dingtalk` 工具，AI 可自主向钉钉群推送状态通报与卡片。

## 配置指南

### 1. 企业自建机器人（双向会话）

1. 登录 [钉钉开放平台](https://open.dingtalk.com/)；
2. 进入「应用开发」→「企业内部开发」→ 创建应用；
3. 在「开发配置」中获取 `AppKey` 与 `AppSecret`；
4. 添加「机器人」能力，配置机器人名称与头像；
5. 在「权限管理」中授予机器人相关消息权限；
6. 在 pi-web-ui 钉钉面板填入 `AppKey` 与 `AppSecret`，勾选「启用钉钉机器人双向会话」。

### 2. 群自定义机器人 Webhook（快捷推送）

1. 在钉钉群设置中，选择「群机器人」→「添加机器人」→「自定义」；
2. 安全设置建议勾选「加签」，复制 `SEC...` 开头的密钥；
3. 复制生成的 Webhook 完整地址；
4. 在 pi-web-ui 钉钉面板填入 Webhook 地址与可选加签密钥即可。
