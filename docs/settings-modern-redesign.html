什么是 MCP？

Model Context Protocol 是目前工业界统一的智能体外部资源集成协议。它支持在本地或远程按需暴露工具与资源提示词。

安全提示：

严禁将包含 root 权限的执行器直接暴露给非受信智能体。建议配合安全审批规则三档使用。
