1. 词级差异高亮 (Word-level)

不仅标出行变色，更计算出该行中具体增加/修改的变量或短语（深绿/深红背景），1 秒看清微小改动。

2. 视图三态任意切

默认紧凑 Unified；需精细比对时切 Split；调试 Agent 参数时一键回切 Raw JSON，完全不破坏排障能力。

🛠️ 架构与系统级根本解决路线（跳出打地鼠视角）
为什么单纯在前端写两个 if (block.name === 'edit') 是“头痛医头”？以下是根本性系统设计剖析：
+----------------------------------------------------------------------------------------+ | 1. 服务端事实源与上下文预算保障 | | | | [Agent Core / SDK] | | | | | |-- edit 成功执行 --> result.details: { diff, patch, firstChangedLine } (已原生具备) | | | | | |-- write 成功执行 -> 守卫 details 预算 <= 64KB (AGENTS.md 硬规则) | | 服务端仅注入 { isNewFile: boolean, totalLines: number, oldLines?: number } | | 绝不注入超大原始文件内容，防止 WS 背压与整包丢弃！ | +----------------------------------------------------------------------------------------+ | v (WebSocket protocol: message_delta / snapshot) +----------------------------------------------------------------------------------------+ | 2. 前端稳健数据模型 (FileMutationModel) | | | | [tool-args.ts] 统一抽象 parser: parseFileMutationArgs(name, argumentsText, details) | | | | | +-- 🛡️ 流式容错: 即使 JSON 刚收到一半 (如 {"path": "src/a.ts", "edits": [...) | | | 正则提前提取 path 与第一段 hunk，显示 "正在替换第 N 行..."，杜绝白屏与抛错 | | | | | +-- 🧩 统一规格: 无论 edit / edit_soft / write / patch，输出标准 UnifiedDiffBlock[] | +----------------------------------------------------------------------------------------+ | v +----------------------------------------------------------------------------------------+ | 3. 表现层复用与多视口一致性保障 | | | | [FileChangeCard.tsx] 核心高内聚组件 | | | | | |-- 1. 普通聊天流卡片 (ToolCallBlock.tsx 展开态) | | |-- 2. 极简/Flow 模式弹窗 (ToolInspectorModal.tsx 居中弹窗) | | |-- 3. 悬浮文件预览抽屉 (file-preview-bridge.ts 侧边抽屉) | | | | ✅ 统一复用 styles.css 中的 .scm-diff 语义色与 CSS 变量 (--green, --red, --bg-elev) | | ✅ 统一满足文字对比度与无障碍规范 (AGENTS.md: semantic-contrast / accent-contrast) | +----------------------------------------------------------------------------------------+

根本性解决步骤清单：

  1. 模型层抽象 (web/src/file-diff.ts)： 解耦具体工具名称，将 edit 的 oldText/newText、SDK 的 details.diff、write 的 content 统一规整化，支持流式容错解析。
  2. 渲染层组件 (web/src/components/FileChangeCard.tsx)： 实现统一差异、分屏差异、词级高亮、行号对齐与折叠保护（默认展示最多 20 行，超额折叠）。
  3. 两处视口无缝联动： 同时接入 ToolCallBlock.tsx（普通对话流）与 ToolInspectorModal.tsx（Flow 检查器模式），保证全站一致体验。
  4. 细节打磨与安全测试： 严格遵守 AGENTS.md 规范（details ≤64KB、CSS 变量先定义后引用、文字对比度合规），并补充单元测试 tests/unit/file-change-card.test.ts。
