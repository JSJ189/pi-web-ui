当前版本为什么让人“感觉很难受”？（4 处严重几何对齐错位）

1. 卡片外框三级狗牙错位

普通卡片从 0px 起始；父卡片因外部挂了 18px 箭头被推到 22px；子卡片又有 padding-left: 14px。三个卡片的外边缘没有一个是齐的！

2. 树枝引导线脱节（偏离 5px）

现存 CSS 中的 ::before 折角线硬编码在 left: 6px，而上方展开箭头的旋转中心点在 left: 11px，导致连线悬空在箭头左侧，没有对准。

3. 长字 Badge 挤占主标题空间

在窄侧栏（220~260px）里，“子代理”胶囊占去近 50px，加上消息图标和缩进，导致任务标题只能露 4~5 个汉字（如“请计算 12...”），信息完全不可读。

4. 标题与副标题纵向脱节

主标题被“子代理”徽标向右硬推，而第二行的“7 条消息”没有缩进，依然顶格，导致上下两行文字左边距完全不对齐，视觉极为毛糙。

🛠️ 落地建议与极简重构思路（首选方案 A）

要彻底解决用户指出的“对不齐感觉难受”，最立竿见影且工程成本极低的做法是采用方案 A：

  1. 消灭外框狗牙错位：将 .lp-tree-caret 从 .lp-row 的左侧挤压位移，收纳进 .session-item 内统一的 18px .session-icon-wrap 槽位中，或者让父会话的卡片左边缘与普通会话保持严格 0px 齐平。
  2. 同轴校准树枝线：现有的 .lp-row.lp-sub::before 的 left: 6px 是导致与 11px 箭头偏心的罪魁祸首。统一将基准锚点锁定在 left: 17px，树线直插箭头正下方，严丝合缝。
  3. 精简子代理徽标：将 subagent-badge 改为专用的分支图标（如 FiGitBranch）或将其移至副标题行的“7 条消息 · 子代理”，释放长达 50px 的标题宽度，窄屏侧栏下不再把标题腰斩。
